# Google Play Store Analytics — Internship

Extension of the Google Play Store training project implementing six performance-based analytics tasks with Python, Pandas, Plotly and a web dashboard.

## Tasks
1. Filtered Bubble Chart
2. Interactive Choropleth
3. Install Trend Time Series
4. Cumulative Installs Stacked Area
5. Category Rating/Reviews Grouped Bar
6. Installs vs Revenue Dual-Axis

Implementation in progress.
